# Documentation Archive

This folder contains historical migration/runbook documents that are no longer part of the active modern runtime workflow.

Use active docs in `docs/` and root `README.md` for current commands and support policy.

## Structure

- `legacy/`: historical documents retained for traceability (legacy AMD/RequireJS retirement planning, pre-slice notes, and superseded migration runbooks).

## Policy

- New active workflow guidance should not be added under `docs/archive/**`.
- When an active doc becomes historical-only, move it here and update references.
