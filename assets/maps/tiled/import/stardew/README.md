# Stardew Valley asset imports (dev placeholders)

These sheets are extracted from a locally-owned copy of Stardew Valley
(ConcernedApe). They are **development placeholders for private use only**
and must not ship in any public build or be redistributed.

Source: ~/dev/StardewXnbHack/Content (unpacked-ts)
Imported: 2026-06-09

| tileset | source | content |
| --- | --- | --- |
| stardew-outdoors-spring | Maps/spring_outdoorsTileSheet.png | ground, transitions (wang sets: sdv-dirt-grass, sdv-water-grass), trees, props |
| stardew-outdoors2-spring | Maps/spring_outdoorsTileSheet2.png | additional outdoor terrain/props |
| stardew-town-spring | Maps/spring_town.png | town buildings, roads, fences |
| stardew-beach-spring | Maps/spring_beach.png | beach terrain and props |
| stardew-mine | Maps/Mines/mine.png | mine walls/floors |
| stardew-objects | Maps/springobjects.png | items/objects grid (crops, tools, forage) |
| stardew-houses | Buildings/houses.png | farmhouse exteriors |

Wang sets on the outdoors sheet were generated by palette-pair quadrant
classification (same technique as the native overlay-* sets). To use in
Tiled: open a map, add one of these .tsj tilesets, pick a terrain set in
the Terrain Sets panel and paint.

Characters/TerrainFeatures/TileSheets remain packed (.xnb) in the source
dump and are not imported; unpack with StardewXnbHack if needed.
